# Profile App — экран профиля на Jetpack Compose

## Описание проекта
Приложение отображает экран профиля пользователя с использованием Jetpack Compose. Реализованы базовые компоненты пользовательского интерфейса, управление состоянием и интерактивность.

## Функциональность
- Отображение аватара пользователя.
- Отображение имени, статуса и количества подписчиков.
- Кнопка «Подписаться» / «Отписаться» с изменением состояния.
- Редактирование имени пользователя через TextField.
- Кнопка сброса имени.
- Счётчик нажатий с кнопкой увеличения.
- Предпросмотр компонентов с помощью @Preview.

## Технологии
- **Язык программирования:** Kotlin
- **UI-фреймворк:** Jetpack Compose
- **Среда разработки:** Android Studio
- **Минимальная версия Android:** API 24

## Структура проекта
- `data/User.kt` — модель данных пользователя.
- `ui/ProfileScreen.kt` — основной экран профиля.
- `ui/components/Avatar.kt` — компонент аватара.
- `ui/components/ProfileInfo.kt` — компонент информации о пользователе.
- `ui/components/ActionButtons.kt` — компонент кнопок.
- `MainActivity.kt` — главная Activity приложения.
